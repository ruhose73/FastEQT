# data_processors/ — Подготовка входных данных

Скрипты для преобразования сырых сейсмических данных и метаданных станций в формат, пригодный для обработки пайплайном EQT.

Запускать из корня репозитория: `python data_processors/main.py`

---

## Модули

### `main.py` — Точка входа

Координирует запуск двух процессоров: метаданных станций и сейсмических файлов. Проверяет наличие входных и выходных директорий перед запуском каждого шага.

**Шаг 1 — Метаданные:** если существуют папка с XML-файлами и путь для выходного JSON, запускает `combine_inventories_to_json()` из `metadata_processor.py`.

**Шаг 2 — Сейсмические файлы:** если существуют входная SDS-директория и выходная папка, запускает `geofile_processor()` для всех подпапок станций.

**Настраиваемые пути** (задаются в начале файла):

```python
metadata_xml_folder_path   = '../../../../science/geodata/Metadata/RU'
json_stationlist_output_path = 'json/station_list.json'
geofile_input_directory    = '../../../science/geodata/SDS/2024/RU'
geofile_output_directory   = 'geo-files'
```

```bash
python data_processors/main.py
```

### `geofile_processor.py` — Конвертер SEED-файлов

Преобразует суточные SEED-файлы из SDS-архива в формат имён файлов, который принимает EQTransformer.

**Проблема:** оригинальные файлы SDS имеют имена вида `RU.SOC.U4.BHE.D.2024.001`, где `001` — порядковый номер дня в году. EQT ожидает файлы с явными временными метками: `RU.SOC.U4.BHE.D__20240101T000000Z__20240102T000000Z`.

**Что делает:**
1. Обходит все станционные подпапки в исходной директории
2. Для каждого файла извлекает порядковый номер дня из имени
3. Вычисляет календарную дату и проверяет, попадает ли она в целевой месяц (`target_month` / `target_year`)
4. Формирует новое имя с ISO-временными метками начала и конца суток
5. Копирует файл с новым именем в выходную директорию

**Формат преобразования:**
```
RU.SOC.U4.BHE.D.2024.001  →  RU.SOC.U4.BHE.D__20240101T000000Z__20240102T000000Z
```

Файлы вне целевого месяца игнорируются — это позволяет обрабатывать только нужный период без ручной фильтрации.

### `metadata_processor.py` — Конвертер метаданных станций

Преобразует XML-файлы метаданных сети (формат StationXML / FDSN) в JSON-файлы формата, который используют скрипты пайплайна для получения координат станций.

**Выходной формат JSON** (один файл на станцию):
```json
{
  "SOC": {
    "network": "RU",
    "channels": ["BHE", "BHN", "BHZ"],
    "coords": [43.57, 39.763, 54.0]
  }
}
```

**Что делает:**

`read_inventory_file(file_path)` — читает один XML-файл через ObsPy `read_inventory()`, извлекает код сети, код станции, координаты (lat, lon, elevation) и список каналов. При дублирующихся каналах оставляет только наиболее свежие (по дате начала).

`combine_inventories_to_json(xml_folder_path, json_output_path)` — обходит все XML-файлы в папке, объединяет данные по станциям и сохраняет единый JSON-файл. Если станция встречается в нескольких XML, каналы объединяются.

Готовые JSON-файлы станций хранятся в `json/station_*.json` и используются детектором и ассоциаторами для геолокации и вывода координат в CSV.
