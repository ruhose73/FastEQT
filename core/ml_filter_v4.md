# ml_filter_v4.py — описание алгоритма

## Цель

Фильтрует `associations.xml` ассоциатора, оставляя только события с локальной магнитудой ML выше порога. Работает полностью в памяти: читает MSEED-файлы оконно, снимает инструментальный ответ, кэширует амплитуды в CSV.

---

## Формула ML (Дягилев et al. 2023, формула 5б)

```
ML = lg(A_нм) + 1.024·lg(R) + 0.001648·R − 1.889 + S
```

| Член | Физический смысл |
|---|---|
| `lg(A_нм)` | логарифм пикового смещения грунта в нанометрах — мера амплитуды S-волны на станции |
| `1.024·lg(R)` | геометрическое расхождение: амплитуда убывает как ~1/R при распространении |
| `0.001648·R` | неупругое затухание: экспоненциальное поглощение энергии в среде |
| `−1.889` | константа калибровки формулы для Терско-Каспийского прогиба |
| `S` | станционная поправка (0 по умолчанию) — компенсирует локальные геологические условия под станцией |

Расстояние R вычисляется не по координатам гипоцентра, а по S-P формуле:

```
R = Vp·Vs / (Vp − Vs) · ΔT(S-P)
```

где `ΔT = t_S − t_P` в секундах, `Vp=6.0`, `Vs=3.4883` км/с, что даёт коэффициент `k ≈ 7.84` км/с. Это позволяет не использовать гипоцентральную локацию — достаточно пиков P и S из ассоциатора.

## Измерение амплитуды A

1. Из MSEED читается окно `[t_S − 60с, t_S + 5с + 60с]` (READ_MARGIN_SEC=60, WIN_SEC=5).
2. Снимается инструментальный ответ через ObsPy `remove_response(output='DISP')` → смещение в метрах.
3. Применяется полосовой фильтр **1–5 Гц** (4-й порядок, нулевая фаза).
4. Берётся `max(|data|)` на окне `[t_S, t_S + 5с]`.
5. Переводится в нанометры: `A_нм = A_метры × 1e9`.

**Почему полосовой фильтр 1–5 Гц:** формула Дягилева 2023 калибровалась на WA-симулированных записях (рабочая полоса Wood-Anderson T≈0.2–0.6 с → f≈1.7–5 Гц). Без этого фильтра микросейсмический шум 0.5–1 Гц завышает ML на 0.5–1.0 единицы.

**Почему горизонтальная компонента:** приоритет E > N > Z. S-волна максимальна на горизонталях.

## Многоступенчатая фильтрация ML для одного события

Для каждого события собирается набор оценок от разных станций. Задача — получить одно надёжное число ML из этого набора, отбросив плохие измерения.

### Что вычисляется на каждой станции

Для станции `i` с расстоянием `R_i` (км) и амплитудой `A_i` (нм):

```
ML_i = lg(A_i) + 1.024·lg(R_i) + 0.001648·R_i − 1.889 + S_i
```

Формула инвертирует зависимость от расстояния и оставляет только вклад источника. В идеале все `ML_i` по разным станциям должны совпадать. На практике они расходятся из-за разной геологии под станцией, помех на конкретной записи, ошибок пика P или S, рефракции и анизотропии среды.

### Шаг 1: Физические отсечки (`_ml_entries`)

До статистики отбрасываются физически невалидные точки:

| Условие | Значение | Причина |
|---|---|---|
| `R < 20` км | R_MIN_KM | near-source, формула нелинейна |
| `R > 600` км | R_MAX_KM | вне калибровочного диапазона |
| `A < 0.005` нм | A_NM_MIN | ниже уровня шума, артефакт remove_response |
| `A > 1e6` нм | A_MAX_NM | физически невозможно (>1 мм), сбой обработки |

После этого остаётся список `entries = [(sta, R_i, A_i, ML_i), ...]`.

### Шаг 2: σ-фильтр выбросов (`_filter_by_sigma_v2`)

**Вычисление центра:**
```
M_med = median(ML_1, ML_2, ..., ML_N)
```
Медиана, а не среднее — потому что она устойчива к выбросам. Если одна станция даёт ML=5.0 при остальных ML≈1.5, среднее сдвинется к 2.0, медиана останется на 1.5.

**Вычисление разброса:**
```
σ = std(ML_1, ML_2, ..., ML_N)
```

**Порог и проверка каждой станции:**
```
thr = 1.5 · σ

|ML_i − M_med| ≤ thr  →  станция остаётся
|ML_i − M_med| > thr  →  станция-выброс, отбрасывается
```

**Пример** с 6 станциями:

| Станция | R, км | ML_i | |
|---------|-------|------|-|
| BEYR    | 45    | 1.42 | |
| DOMR    | 67    | 1.51 | |
| GOYR    | 89    | 1.48 | |
| SHA1    | 112   | 1.55 | |
| MRNR    | 134   | 1.61 | |
| NEUR    | 158   | 3.20 | ← плохой пик |

```
M_med = median([1.42, 1.51, 1.48, 1.55, 1.61, 3.20]) = 1.53
σ     = std([...]) = 0.63
thr   = 1.5 · 0.63 = 0.94

BEYR:  |1.42 − 1.53| = 0.11 ≤ 0.94  →  OK
DOMR:  |1.51 − 1.53| = 0.02 ≤ 0.94  →  OK
GOYR:  |1.48 − 1.53| = 0.05 ≤ 0.94  →  OK
SHA1:  |1.55 − 1.53| = 0.02 ≤ 0.94  →  OK
MRNR:  |1.61 − 1.53| = 0.08 ≤ 0.94  →  OK
NEUR:  |3.20 − 1.53| = 1.67 > 0.94  →  ВЫБРОС
```

**Защита от деградации:** если после удаления выбросов осталось меньше N_MIN_STA=4 станций — фильтрация отменяется, возвращается исходный список. Лучше иметь шумный ML из 4 станций, чем не иметь ML вообще.

**Почему 1.5σ, а не 2σ или 3σ:**

| Порог | Поведение |
|-------|-----------|
| 3σ    | слишком мягкий — явные выбросы проходят |
| 2σ    | стандартный статистический, но при малых сетях (4–6 станций) σ сама нестабильна |
| **1.5σ** | умеренно строгий: убирает станции с отклонением >1.5σ от разброса сети, оставляет нормальные флуктуации |

При типичном разбросе ML по станциям σ≈0.3–0.5 порог составляет 0.45–0.75 единиц магнитуды — это физически разумно.

### Шаг 3: Финальная оценка

```
ML_события = mean(ML_i по оставшимся станциям)
```

Среднее (а не медиана) — потому что после 2σ-фильтрации выбросов уже нет, оставшиеся `ML_i` близки друг к другу. Среднее тогда точнее медианы (меньше дисперсия при симметричном распределении).

### Итоговая схема

```
entries (N станций с ML_i)
        │
        ▼
[физические отсечки] → убираем R<20, R>600, A<0.005нм, A>1мм
        │
        ▼
   N < 4 ?  →  ML = None (нет оценки)
        │
        ▼
  M_med = median(ML_i)
  σ     = std(ML_i)
  thr   = 1.5·σ
        │
        ▼
  убираем |ML_i − M_med| > thr
        │
        ▼
   N < 4 ?  →  откат, берём все (до фильтра)
        │
        ▼
  ML_события = mean(ML_i по оставшимся)
```

## Параллелизация по станциям

Станции делятся round-robin на N_WORKERS=4 групп. Каждый поток работает только со своим набором станций — нет конкуренции за файлы, нет блокировок. Внутри потока события группируются по файлу MSEED и кластеризуются по времени (MAX_GROUP_SPAN_SEC=300 с), чтобы читать один файл одним вызовом `obspy_read`.

---

## Кэширование амплитуд

Вычисление `remove_response` дорогое. Результаты `{(pub_id, sta): A_метры}` сохраняются в `amps_wa.csv`. При повторном запуске кэш подгружается, MSEED не перечитывается. Пересборка: `--rebuild-cache`.

## Основные параметры

| Параметр | Значение | Смысл |
|---|---|---|
| `ML_B_LOG` | 1.024 | коэф. геометрического расхождения |
| `ML_B_LIN` | 0.001648 | коэф. неупругого затухания, 1/км |
| `ML_C` | −1.889 | калибровочная константа |
| `VP / VS` | 6.0 / 3.4883 км/с | скорости для S-P формулы |
| `R_MIN_KM` | 20 | ближняя граница применимости формулы |
| `R_MAX_KM` | 600 | дальняя граница |
| `WIN_SEC` | 5 | окно измерения амплитуды S-волны |
| `BP_FREQMIN/MAX` | 1–5 Гц | полоса WA-эквивалента |
| `A_NM_MIN` | 0.005 нм | минимальная физическая амплитуда |
| `A_MAX_NM` | 1e6 нм | максимальная физическая амплитуда |
| `ML_OUTLIER_SIGMA` | 1.5 | порог σ-фильтра выбросов по станциям |
| `N_MIN_STA` | 4 | минимум станций для оценки ML |
| `N_WORKERS` | 4 | потоков (по группам станций) |
