# Дягилев, Габсатарова, Селиванова (2023) — источник формулы ML в `ml_filter_v5.py`

Разбор статьи «Шкала локальных магнитуд ML для землетрясений в Терско-Каспийском прогибе» (Российский сейсмологический журнал, 2023, т. 5, № 2, с. 19–31, DOI: 10.35540/2686-7907.2023.2.02) и её связь с формулой, зашитой в `core/ml_filter_v5.py`.

---

## 1. Что и на каких данных калибровалось

- Регион: центральная часть Терско-Каспийского прогиба, южная часть Чеченской Республики (зона сочленения с Большим Кавказом).
- Данные: 64 землетрясения 2020–2022 гг. (афтершоковая последовательность двух толчков M=4.5–4.8 в районе Чёрных гор), записаны 58 станциями на расстояниях 25–526 км.
- Измерения: амплитуды и периоды на **симулированных записях короткопериодного прибора Wood-Anderson (WA)**, в максимальной фазе на горизонтальных компонентах, из бюллетеня в формате ISF, сформированного программой WSG (ФИЦ ЕГС РАН).
- Расчёт калибровочной функции — программа **MagScale** (Дягилев, 2022), реализующая методику NMSOP (Bormann et al., 2013).
- **Важно: `R` в этой статье — гипоцентральное расстояние из локации события** (уже посчитанное WSG/каталогом), а не что-то, выводимое из разности времён S-P. Статья **не строит и не использует скоростную модель (Vp/Vs)** — вопрос происхождения расстояния для неё не стоит, оно берётся готовым.

## 2. Формула и её происхождение

Классическая форма ML (Рихтер 1935, модификация Hutton & Boore 1987, стандарт IASPEI):

```
ML = lg(A) + a·lg(R) + b·R + c        (३, в статье — формула (3))
```

где `A` — максимальное смещение грунта в нм, `R` — гипоцентральное расстояние в км.

Авторы посчитали коэффициенты `a`, `b`, `c` двумя способами на одной и той же выборке:

| Вариант | Данные | a | b | c | Формула в статье |
|---|---|---|---|---|---|
| 1 (строгий) | 571 измерение — только те, где ещё и частные коэффициенты `a`,`b` по отдельному землетрясению попали в допустимый диапазон (`0.5≤a≤1.5`, `0≤b≤0.01`) | 0.964 | 0.001847 | −1.791 | (4б) |
| 2 (все данные) | 749 измерений — только базовые ограничения по амплитуде/расстоянию/магнитуде, без пофильтровки по частным a/b | **1.024** | **0.001648** | **−1.889** | **(5б)** |

Авторы явно отмечают: разница между вариантами по итоговому ML не превышает **0.04** магнитудных единицы во всём диапазоне расстояний (25–526 км) — то есть выбор варианта малозначим на практике, оба хорошо согласуются.

**Наш код (`core/ml_filter_v5.py`) использует ровно вариант 2, формулу (5б):**
```
ML = lg(A) + 1.024·lg(R) + 0.001648·R − 1.889 + S
```
Совпадение с кодом дословное, с точностью до всех трёх коэффициентов — это прямой первоисточник формулы в `ml_filter_v5.py`. Свободный член `−1.889` — не произвольная константа, а результат МНК-калибровки этой конкретной формулы к опорной точке Рихтера (`ML=3` на `R=100` км при `A_WA=1` мм), пересчитанной через смещения грунта в нм (не амплитуды WA в мм).

## 3. Диапазон применимости

Статья: калибровка считалась надёжной для землетрясений `−1.0 ≤ ML ≤ 6.0`, гипоцентральных расстояний `10 ≤ R ≤ 1000` км, минимум 4 станции на событие, амплитуды `1 ≤ A ≤ 10⁶` нм.

Наш код (`ml_filter_v5.py`, см. `core/ml_filter_v5.md`): `R_MIN_KM=20`, `R_MAX_KM=600`, `N_MIN_STA=4`, `A_NM_MIN=0.005` нм, `A_MAX_NM=10⁶` нм.

Сопоставление: нижняя и верхняя граница по `R` у нас **строже** (уже), чем в статье (`20–600` внутри `10–1000`) — сознательно консервативный выбор, не противоречие. Нижний порог по амплитуде у нас ниже (`0.005` нм против `1` нм в статье) — вероятно, потому что источник амплитуды в статье (визуальный замер оператором в WSG на симулированной записи WA) и в нашем коде (`remove_response` на реальной цифровой записи, `EqT_utils`-пайплайн) физически разные измерительные цепочки с разным уровнем шума; порог `4` станции минимум совпадает дословно.

## 4. Станционные поправки `S` — что в статье, и почему не используются сейчас

Формула калибровки (2) в статье явно включает станционную поправку `S`:
```
σ(∆) = a·lg(∆/100) + b·(∆−100) + 3 + S
```
Поправка считается как среднее отклонение частных оценок ML по станции от среднего ML события по всем станциям. В статье приведены `S` для **28 станций** (табл. 2), диапазон примерно от −0.44 (KMKR) до +0.50 (ARNR, MRMR), общая невязка шкалы снижается с ±0.26 (без поправок) до ±0.15 (с поправками).

**Прямое сопоставление кодов станций из табл. 2 со списком активных станций сети (`geofiles/`) даёт 23 совпадения из 28:**
```
AKT, ARKR, ARNR, BTLR, BUJR, DLMR, DRN, DVE, GROC, HNZR, KMKR, KORR,
LACR, LSNR, MAK, PYA1, SGKR, SHA1, STDR, TLTR, TRKR, UNCR, URKR
```
(не совпали: `GNBR, GNI, KIV, MRMR, PRTR` — этих кодов нет в текущем `geofiles/`).

**Несмотря на численное совпадение кодов, этими значениями сейчас пользоваться не стоит (по мнению Р.А. Дягилева):** поправки посчитаны по данным 2020–2022 гг., с тех пор на сети менялось оборудование — значения были скорее тестовыми, чем пригодными для текущих расчётов ML. `ml_filter_v5.py` работает с `S=0` по умолчанию; механизм (`--sta-corrections`) доступен, если/когда появится актуальная калибровка под нынешнее состояние сети.

Отдельно интересное наблюдение из статьи (годится для физического документа, без цифр): площадное распределение `S` не случайно — авторы делят территорию на западную/северо-западную зону (положительные поправки) и северную/северо-восточную/восточную (отрицательные), связывая это с двумя тектоническими разломами и с различием грунтов под конкретными станциями (пример в статье — станции «Грозный» на осадочных породах и «Ведено» на скальном грунте в 30 км друг от друга дают разные по знаку поправки).

## 5. Для Этапа 2 (физический документ) — без формул

- Идея логарифма амплитуды: сила толчка растёт на порядки, поэтому магнитуда — логарифмическая шкала (аналогично шкале землетрясений, которую человек интуитивно понимает — "на 1 больше" значит "в ~10 раз сильнее по амплитуде записи").
- Идея поправки на расстояние: волна теряет энергию по двум причинам одновременно — геометрически расходится (как круги на воде, чем дальше — тем "тоньше" фронт волны на единицу площади) и поглощается средой (переходит в тепло по пути). Первое даёт член с `lg(R)`, второе — линейный член с `R`. Оба откалиброваны на реальных землетрясениях именно в этом районе, не заимствованы из общей теории.
- Идея станционной поправки: одна и та же по силе волна на разных станциях запишется чуть по-разному просто из-за грунта под сейсмометром (мягкие осадочные породы могут усиливать колебания, скала — нет) — поправка компенсирует этот локальный эффект, если она надёжно откалибрована.

## 6. Для Этапа 3 (технический документ)

- Явно указать источник формулы: Дягилев и др. 2023, уравнение (5б), «вариант 2» из двух вариантов калибровки в статье.
- Явно указать, что происхождение `Vp=6.0`/`Vs=3.4883` км/с в `ml_filter_v5.py`/`validate_associator_v2.py` — **не из этой статьи**, а получено отдельно от научного консультанта (Р.А. Дягилев, ФИЦ ЕГС РАН), не задокументировано в открытой публикации.
- Явно указать, что `R` в оригинальной калибровке статьи — расстояние из полноценной локации (с глубиной), а наш пайплайн такого расстояния не имеет (см. правило №20 `CLAUDE.md` — локации нет вообще) и подставляет в ту же формулу расстояние, оценённое по разности времён S-P через тот же `Vp`/`Vs`. Это не ошибка, а осознанная замена одного входа формулы на физически иной, но сопоставимый по смыслу — стоит явно проговорить как методологическую особенность применения чужой калибровки, а не как готовую эквивалентность.
- Станционные поправки — описать механизм (`--sta-corrections`, параметр `S`), сослаться на эту статью как на пример того, как вообще может выглядеть готовый набор `S`, но явно указать, что имеющийся набор для наших станций признан устаревшим и не используется.
